## Four-problem strip

1. **Leads are getting missed** — Some inquiries never get followed up with.
2. **Too much time is wasted** — Work is being repeated or done manually when it doesn’t need to be.
3. **Information is scattered** — Important emails, files, spreadsheets, tasks, and information are hard to keep organized.
4. **Your systems aren’t helping enough** — Your website, software, or processes aren’t working as well as they should.

## Working method

Headline:

> WE FIND THE PROBLEM. THEN WE HELP FIX IT.

Supporting copy:

> We look at what isn’t working, decide what matters most, and help put a practical solution in place.

1. **Assess** — Find what’s getting in the way.
2. **Prioritize** — Decide what will make the biggest difference first.
3. **Improve** — Fix, build, automate, or organize what needs to work better.

## Visual mechanisms

Six restrained, responsive HTML/CSS flows make the capability section understandable by scanning:

- Website → Inquiry → Follow-up → Customer
- Manual task → Automation → Done
- Email + Drive + Sheets + Calendar → One clear workflow
- Clear message → Easy action → More inquiries
- Repeatable work → Practical AI help → Time saved
- Problem → Priority → Better process

The flows use meaningful live text, restrained charcoal/cream/gold surfaces, visible arrows, compact labels, and no stock photography, fake screenshots, fake dashboards, generated evidence, or animation dependency.
