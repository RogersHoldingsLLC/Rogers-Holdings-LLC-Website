From the website to the workbench.

The website

Browse six example ceramics, compare dimensions and care notes, filter the collection, then build a sample bag and review a simulated checkout. No contact or payment details are requested.

The spreadsheet model

Review a browser-based dispatch worksheet with pickup and shipping filters, payment and delivery checks, and clear distinctions between packed, blocked and ready-to-release orders.

How the sample handoff works: After simulated checkout, the link passes only a sample unit count to a preview panel on the tracker page. It does not add an order to the worksheet, connect to Google Sheets or save a record. Both demos use example data; there is no live integration.

Dispatch desk in two formats

Both views use the sample dispatch queue, including order SE-106 held for payment. Edits stay where you make them.

What we did

Built both sides of one example ceramics project: a product-led storefront with a sample bag and checkout, plus a dispatch spreadsheet model with route-specific release checks and queue logic.

How it helps

Shows how product information, order review and fulfillment planning can fit into one workflow. Customers can understand an item while the studio can distinguish packed work from work ready to leave. These are demonstrated capabilities, not measured business results.
