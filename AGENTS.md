# Rogers Holdings Website — Codex Instructions

## Identity

This project is the public website for Rogers Holdings LLC.

## Mission

Clearly explain Rogers Holdings services, establish credibility, generate qualified leads, and support conversion into paying clients.

## Priorities

1. Clear positioning
2. Professional presentation
3. Lead generation
4. Mobile usability
5. Performance
6. Search visibility
7. Accurate service descriptions

## Operating Rules

1. Preserve the current design unless redesign is explicitly requested.
2. Improve before replacing.
3. Do not change branding casually.
4. Keep copy plain, credible, and client-focused.
5. Avoid unsupported claims.
6. Test mobile behavior after meaningful layout changes.
7. Protect metadata, favicons, social-sharing images, analytics, and search files.
8. Review Git status before and after work.
9. Never mix Headquarters, Business Optimization Platform code, Blue Bomber, or unrelated work into this project.

## Required Reading

Before substantial work, read:

- README.md
- package.json
- index.html
- relevant assets and deployment configuration

## Output Rules

- Website code and assets stay in this project.
- Planning documents belong under docs/ if that folder exists.
- Do not create random duplicate image folders.
- Record meaningful release changes in the approved project documentation.
